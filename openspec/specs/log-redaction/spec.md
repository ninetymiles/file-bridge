# log-redaction Specification

## Purpose

约束日志输出中不得出现凭证、令牌、下载码等敏感信息，使排障日志可以安全地被采集与分享；该能力只记录实现要求，由实现与代码评审核验，不设自动化测试。

## Requirements

### Requirement: 日志不输出敏感凭证

系统在任意日志级别下 MUST NOT 输出 `client_secret`、访问令牌、API Key 明文、图片/文件下载码与带签名的临时下载 URL。允许输出脱敏后的令牌指纹（保留少量首尾字符）。本要求由实现与代码评审核验，不建立自动化测试。

#### Scenario: 凭证不出现在日志输出

- **WHEN** 服务以 DEBUG 或 INFO 级别运行并处理任意消息
- **THEN** 日志输出中不出现上述敏感值；出现令牌时仅以脱敏指纹形式呈现
- **THEN** 该结果由实现评审确认，不以自动化用例核验
