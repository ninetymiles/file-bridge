## MODIFIED Requirements

### Requirement: “重建索引”维护指令
系统 SHALL 支持用户通过发送包含"重建索引"的文本指令，触发清理 SQLite 中已在磁盘上不存在的记录。执行重建前，系统 SHALL 按 `storage-warmup` 能力的定义执行一次存储预热：3 秒内就绪则静默执行；超时则先向指令发送者回复一条固定措辞的存储唤醒提示，再执行重建。无论是否发送唤醒提示，完成后 SHALL 向发送者回复"索引重建完成"的确认消息（文案规则不变）。探针或重建本身发生错误时，按既有命令错误处理规则处理（唤醒提示已发送则保留）。

#### Scenario: 触发重建索引指令
- **WHEN** 用户在单聊或群聊中发送包含"重建索引"的文本指令
- **THEN** 系统遍历 SQLite 中的记录，核验每个文件在磁盘上是否存在，删除物理文件不存在的记录，并向发送者回复"索引重建完成，清理元数据 XX 条"的确认消息

#### Scenario: 冷盘时重建索引先收到唤醒提示
- **WHEN** 用户发送"重建索引"指令，且存储卷处于休眠状态，预热探针 3 秒内未完成
- **THEN** 发送者先收到一条固定措辞的"正在唤醒存储服务"提示，探针完成后系统执行重建，并再收到既有的"索引重建完成"结果回复；热盘时则只收到结果回复
