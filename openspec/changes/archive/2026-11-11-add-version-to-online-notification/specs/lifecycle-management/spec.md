# Spec Delta

## MODIFIED Requirements

### Requirement: 上线与离线主动通知
系统 SHALL 在服务启动就绪后向预设的钉钉会话发送上线通知，并在停机清理前发送离线通知；未配置目标时保持静默。上线通知正文 SHALL 包含当前运行版本，群聊与单聊目标一致；离线通知 SHALL NOT 包含版本信息。

#### Scenario: 配置了通知目标时的上线通知
- **WHEN** 配置了有效的群聊 ID 或单聊用户 ID 且服务初始化就绪
- **THEN** 系统向指定会话发送“服务已上线”的主动通知消息，正文包含当前运行版本

#### Scenario: 配置了通知目标时的离线通知
- **WHEN** 配置了有效的群聊 ID 或单聊用户 ID 且接收到停机信号
- **THEN** 系统在断开长连接前向指定会话发送“服务正在离线”的主动通知消息，正文不包含版本信息

#### Scenario: 未配置通知目标时的静默处理
- **WHEN** 未配置任何通知目标（既无群聊 ID 亦无单聊用户 ID）
- **THEN** 系统跳过上下线通知发送流程，不记录错误且不阻断应用的正常启动和停机

#### Scenario: 群聊与单聊上线通知包含同一版本
- **WHEN** 同时配置群聊与单聊通知目标且当前运行版本为 `1.2.0`
- **THEN** 两个目标收到的上线通知正文均包含 `当前版本：1.2.0`，且两者显示一致

#### Scenario: 未注入版本时显示 dev
- **WHEN** 运行时未提供版本号（变量缺失或为空串）
- **THEN** 上线通知正文的版本行显示 `当前版本：dev`
