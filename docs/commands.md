# 聊天指令说明

## 触发方式

命令走独立的命令处理链，优先于媒体文件处理链：

1. 只处理 `text` 与 `richText` 消息。
2. 含「多少」「状态」或以「吗」「怎么样」等结尾的疑问句不会进入命令匹配，只会得到能力说明回复。
3. 默认使用字面子串匹配；设置 `SEMANTIC_COMMAND_ENABLED=true` 后切换为语义匹配。两种匹配器共用同一份命令目录。
4. 多个命令可能命中时，按命令目录的声明顺序决定优先级。

## 重建索引（`rebuild_index`）

触发短语：

- 重建索引
- 重新建立索引
- 重建文件索引
- rebuild index
- 检查索引
- 校验索引
- 检查文件索引
- 同步索引
- 同步文件索引
- 刷新索引
- 刷新文件索引
- 更新索引

行为：校验索引记录对应的文件是否仍在 `OUTPUT_DIR` 中，删除文件已缺失的记录，并返回清理条数与有效条数。该命令只清理、不扫描磁盘补录。

## 统计报告（`index_report`）

触发短语：

- 统计报告
- 生成统计报告
- 索引统计
- 统计索引
- 投稿统计
- 索引报告
- 分析索引
- 分析文件索引

行为：只读查询索引，不修改数据库。报告内容：

- 用户数：按 `sender_id` 去重。
- 文件总数与照片、视频、其他文件的分类数量。
- 媒体类型为空的记录按保存路径的扩展名回退归类。

输出格式：单行 `当前索引总量：N 位用户上传 M 份文件 (照片 X，视频 Y，其他 Z)`；索引为空时回复「索引中暂无文件记录。」。手动指令不展示最近新增，增量信息由每日自动统计报告承担。
